FITZONE — LIST + DETAIL LAB

WHAT IS INCLUDED
- index.html: complete responsive fitness website
- workouts.json: JSON data for three workouts
- workouts.js: List rendering, category filters, Detail modal, JSON loading
- style.css: website and modal styles

HOW TO OPEN
1. Extract the ZIP folder.
2. Double-click index.html to open the site in your browser. The built-in fallback makes the demo work even when the browser blocks local JSON loading.
3. To demonstrate that the data is loaded from workouts.json, open the folder in Visual Studio Code and run index.html with the Live Server extension.

HOW TO TEST
- Scroll to Workouts: the List shows workout cards.
- Use All / Strength / Cardio filters.
- Click VIEW DETAILS to open the Detail modal.
- Close it using X, the backdrop, or Escape.
- Edit workouts.json and refresh while using Live Server to see your changes.

LAB CONCEPTS
List = render all records from JSON into cards.
Detail = find one record by id and show its fields in a modal.
JSON = structured data kept separate from page layout and JavaScript.
